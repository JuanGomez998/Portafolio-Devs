# Portafolio Profesional de Desarrollador Fullstack

¡Bienvenido al código fuente de tu nuevo portafolio profesional! Este proyecto fue diseñado con un enfoque "Pixel Perfect", integrando una paleta de colores moderna, efectos "Glassmorphism" y animaciones fluidas para destacar tu trabajo como desarrollador.

## 🚀 Cómo ejecutar el proyecto localmente

1. **Abre tu terminal en la carpeta del repositorio (`c:\Repo\Portafolio Devs`).**
2. **Instala las dependencias:**
   ```bash
   npm install
   ```
3. **Inicia el servidor de desarrollo:**
   ```bash
   npm run dev
   ```
4. **Visualiza la aplicación:**
   Abre el enlace que se muestra en tu terminal (generalmente `http://localhost:5173`) en tu navegador de preferencia.

## 📁 Estructura del Proyecto
- **/src/components:** Contiene todas las secciones modulares del portafolio (Hero, Navbar, About, Skills, Projects, Services, Contact, Footer).
- **/src/index.css:** Sistema de diseño global, paleta de colores oscuros, utilidades y animaciones.
- **index.html:** Configurado con etiquetas META para SEO.
